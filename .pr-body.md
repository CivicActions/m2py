## Summary

Implements Spec 004: Minimal Control Flow Foundation - the first code generation spec for M2PY. This establishes the core infrastructure for translating MUMPS ASG to executable Python code.

## Changes

### Code Generation Infrastructure
- `src/m2py/codegen/` - New module for Python code generation
  - `__init__.py` - Public API: `generate_python(source, routine_name, validate)`
  - `helpers.py` - MUMPS value model: `m_num()`, `m_truth()`, `m_compare()`
  - `names.py` - `NameTranslator` for MUMPS→Python identifier conversion
  - `emitter.py` - `CodeEmitter` for indent-aware code generation
  - `routine.py` - `RoutineGenerator` for module structure
  - `statements.py` - Statement code generation (SET, WRITE, IF, ELSE, FOR, GOTO, DO, QUIT)
  - `expressions.py` - Expression code generation (literals, variables, operators)

### Runtime Support
- `src/m2py/runtime/__init__.py` - `MUMPSRuntime` class with:
  - Output capture for WRITE statements
  - `execute()` method for running generated code
  - `ExecutionResult` dataclass for results

### Test Infrastructure
- `tests/unit/codegen/conftest.py` - Test fixtures:
  - `generate_python` - Generate Python from MUMPS source
  - `execute_mumps` - Full routine execution with output capture
- `tests/unit/runtime/test_runtime.py` - MUMPSRuntime tests

## Key Implementation Patterns

### Generated Code Structure
```python
from m2py.codegen.helpers import m_num, m_truth, m_compare
from m2py.runtime import MUMPSRuntime

_rt = MUMPSRuntime()
_test = False

def TEST():
    global _test
    X = 1
    _rt.write(str(X))
```

### Name Translation
| MUMPS | Python | Prefix |
|-------|--------|--------|
| `%START` | `_pct_START` | `_pct_` |
| `01` | `_n_01` | `_n_` |
| `if` | `_m_if` | `_m_` |
