# NameTranslator Interface Contract

**Component**: `src/m2py/core/names.py`  
**Type**: Utility Module (static methods)

## Purpose

Bidirectional translation between MUMPS identifiers and valid Python identifiers. This is the **single source of truth** for name translation, shared by codegen and runtime.

## Interface

```python
class NameTranslator:
    """Bidirectional MUMPS ↔ Python name translation.
    
    Constitution VII: Single implementation used by both codegen
    (compile time) and runtime (dynamic resolution) to ensure
    variable names are consistent across all code paths.
    """
    
    PYTHON_KEYWORDS: ClassVar[Set[str]]
    
    @staticmethod
    def to_python(mumps_name: str) -> str:
        """Translate MUMPS identifier to valid Python identifier.
        
        Args:
            mumps_name: A valid MUMPS identifier
            
        Returns:
            A valid Python identifier
            
        Rules:
            %NAME  → _pct_NAME   (percent-prefixed)
            01     → _n_01       (numeric-prefixed)  
            if     → _m_if       (Python keyword collision)
            FOO    → FOO         (unchanged)
        
        Invariant: from_python(to_python(x)) == x for all valid MUMPS names
        """
        ...
    
    @staticmethod
    def from_python(python_name: str) -> str:
        """Translate Python identifier back to MUMPS name.
        
        Args:
            python_name: A Python identifier previously generated by to_python()
            
        Returns:
            The original MUMPS identifier
            
        Note: This is used by runtime when parsing variable names from
        indirection values. Example: If user sets @"_pct_FOO"=5, runtime
        needs to know this refers to MUMPS variable %FOO.
        """
        ...
    
    @staticmethod
    def is_valid_mumps_name(name: str) -> bool:
        """Check if string is a valid MUMPS variable name.
        
        Args:
            name: String to validate
            
        Returns:
            True if valid MUMPS identifier (starts with % or letter,
            followed by alphanumerics)
        
        Used by: IndirectionResolver to validate NAME indirection results
        """
        ...
```

## Test Cases (from MUGJ patterns)

```python
# Basic translation
assert NameTranslator.to_python("%ABC") == "_pct_ABC"
assert NameTranslator.to_python("01") == "_n_01"
assert NameTranslator.to_python("VCOMP") == "VCOMP"

# Keyword collision
assert NameTranslator.to_python("if") == "_m_if"
assert NameTranslator.to_python("for") == "_m_for"

# Round-trip
assert NameTranslator.from_python("_pct_ABC") == "%ABC"
assert NameTranslator.from_python("_n_01") == "01"
assert NameTranslator.from_python("_m_if") == "if"

# Validation
assert NameTranslator.is_valid_mumps_name("X")
assert NameTranslator.is_valid_mumps_name("%FOO")
assert NameTranslator.is_valid_mumps_name("A123")
assert not NameTranslator.is_valid_mumps_name("1+1")
assert not NameTranslator.is_valid_mumps_name("")
assert not NameTranslator.is_valid_mumps_name("X(1)")  # Subscripted
```

## Usage Examples

### Codegen Usage
```python
# In codegen/statements.py
from m2py.core.names import NameTranslator

def generate_set_target(target: MVariable) -> str:
    py_name = NameTranslator.to_python(target.name)
    return f"{py_name} = ..."
```

### Runtime Usage
```python
# In runtime/__init__.py
from m2py.core.names import NameTranslator

def resolve_indirection(self, name_str: str, _scope: Dict) -> Any:
    # Validate that resolved name is valid MUMPS variable
    if not NameTranslator.is_valid_mumps_name(name_str):
        raise VarExpectedError(name_str)
    
    # Translate to Python and look up
    py_name = NameTranslator.to_python(name_str)
    return _scope.get(py_name, "")
```
