# Data Model: Complete Stub Tests

**Feature**: 003-complete-stub-tests  
**Date**: January 4, 2026

## Overview

This feature operates on existing test infrastructure - no new data models are created. This document describes the entities involved in test completion.

## Entities

### Stub Test

A test function that requires implementation.

| Attribute | Type | Description |
|-----------|------|-------------|
| file_path | str | Path to test file |
| test_name | str | Function name (test_*) |
| class_name | str | Containing class (Test*) |
| markers | list[str] | pytest markers (stub, xfail, parser, asg) |
| spec_section | str | MUMPS spec section (e.g., s7_1_5) |
| complexity | enum | LOW, MEDIUM, HIGH |
| batch_id | str | Assigned batch (A1, B1, etc.) |

### Test Batch

A group of related tests to implement together.

| Attribute | Type | Description |
|-----------|------|-------------|
| batch_id | str | Unique identifier (A1-D19) |
| phase | str | A, B, C, or D |
| tests | list[StubTest] | Tests in this batch |
| count | int | Number of tests |
| complexity | enum | LOW, MEDIUM, HIGH |
| status | enum | NOT_STARTED, IN_PROGRESS, COMPLETE |

### Coverage Entry

A row in the coverage matrix.

| Attribute | Type | Description |
|-----------|------|-------------|
| section | str | Spec section identifier |
| parser_status | str | ✅, 🚧, ⏭️, etc. |
| asg_status | str | Test status for ASG layer |
| codegen_status | str | Test status (out of scope) |
| notes | str | Additional context |

## Relationships

```
Test Batch 1──* Stub Test
Stub Test *──1 Spec Section
Coverage Entry *──1 Spec Section
```

## State Transitions

### Stub Test Lifecycle

```
STUB (xfail marker)
    │
    ▼ implement assertions
IMPLEMENTED (xfail removed)
    │
    ▼ tests pass
PASSING (verified)
```

### Batch Lifecycle

```
NOT_STARTED
    │
    ▼ begin batch
IN_PROGRESS
    │
    ▼ all tests passing
COMPLETE
```

## No Schema Changes Required

This feature modifies test files, not application data models. The existing test infrastructure is sufficient:

- pytest markers identify stubs: `@pytest.mark.stub`, `@pytest.mark.xfail`
- Coverage matrix is auto-generated by `utils/audit_tests.py`
- Test organization follows established patterns in `tests/unit/`
